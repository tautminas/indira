## 📖 About

You are a cat named **Indira** with nine lives. Nine and no more. Angry dog created a tricky obstacle course. Can you beat it?

## 🎯 Controls

| Key            | Action     |
| -------------- | ---------- |
| ⬅️ Left Arrow  | Move Left  |
| ➡️ Right Arrow | Move Right |
| ⬆️ Up Arrow    | Jump       |

## ▶️ Run Locally

1. **Install dependencies:**

```bash
   npm install
```

2. **Start the development server:**

```bash
   npm run dev
```

3. **Play the game:** open [http://localhost:8080](http://localhost:8080) in your browser.
